# Albert Sans

Unmodified Google Fonts v4 WOFF2 files, retrieved on 2026-10-05 from the
stylesheet previously used by this website. The existing Helvetica-first
font stack is unchanged. No font is preloaded: browsers that have Helvetica
do not need this fallback.

- Latin: https://fonts.gstatic.com/s/albertsans/v4/i7dOIFdwYjGaAMFtZd_QA1ZbYFc.woff2
- Latin extended: https://fonts.gstatic.com/s/albertsans/v4/i7dOIFdwYjGaAMFtZd_QA1ZVYFeCGg.woff2
- Original stylesheet: https://fonts.googleapis.com/css2?family=Albert+Sans:wght@200;300;400;500&display=swap
- License source: https://github.com/google/fonts/blob/main/ofl/albertsans/OFL.txt

The accompanying `OFL.txt` permits redistribution. Both files are variable
fonts; `src/styles/fonts.css` exposes the same 200–500 weight range and Unicode
subsets as the original stylesheet.
