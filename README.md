# Cattelan Italia Maroc — maquette

Maquette de présentation du site du showroom Cattelan Italia de Casablanca (Triangle d'Or).

- `index.html` : page d'accueil avec le choix de version
- `version-a/` : accueil avec grand titre typographique
- `version-b/` : accueil « Vivre italien, à Casablanca. »

Site statique : il suffit de servir le dossier (GitHub Pages, Cloudflare Pages, Netlify…).
Textes, adresse et horaires entre crochets sont provisoires.
