# Briefs modèles: règles communes

39 modèles, un fichier par famille (`<famille>.md`, généré). Chaque modèle a deux textes à écrire:
`description` (la phrase d'identité) et `content` (la construction et les options).

## Style pour une fiche modèle

Une fiche modèle est un texte de précision. Le style reste calme et concret, avec un nom d'objet ou de matière dans chaque
phrase, mais on ne raconte pas d'histoire que les faits n'apportent pas. Pas de formule d'ambiance sans objet.

- `description` : ouvrir sur ce qu'est le modèle et ce qui le distingue (la forme, la matière, la construction), puis les
  chiffres qui aident à choisir. Une à deux phrases.
- `content` : la matière du piètement, du plateau ou de l'assise, les familles de finitions et les options. Une à
  trois phrases. Aucun chiffre déjà donné dans `description` n'est répété.
- Les traits listés dans le brief sont les seuls éléments de dessin que l'on peut citer.
- Ne jamais déduire une disponibilité, un prix, un délai, une exposition en magasin ou un entretien d'une photo ou d'un
  nom de matière.
- Distinguer le modèle exact de ses déclinaisons (Skorpio en verre n'est pas Skorpio Wood ni Keramik).

## Vocabulaire des données

| Dans les données | À écrire |
|---|---|
| base | piètement (ou « base » quand c'est un fût central) |
| structure | structure |
| plateau | plateau |
| ballast | lest |
| top | plateau |
| pièces / inserts | inserts |
| diffuseur | diffuseur |
| revêtement, assise | revêtement |
| metals | métaux (laques, chromes, finitions brossées) |
| Tissu chaises/lits | tissu |
| simili cuir | similicuir |
| céramique Marmi / KS | décors de céramique Marmi, décor KS |

Ne jamais écrire « Chaise/Lit », « ballast », « top », « pieds » (pour un piètement de table) ni « metals ».

## Faits de rédaction

- Dimensions : « L × P cm, hauteur H cm », toujours avec l'unité. « Piètement de 160 cm », pas « Base de 160 ».
- Compter avant d'écrire un nombre de décors ou de teintes: le nombre vient des données du brief. Exemple : Tyron et
  Butterfly Keramik ont 18 décors Marmi, et 19 avec le décor KS.
- Botero : base « revêtue d'argile ». Zuleika : « habillée de cuir ». Buffet, jamais « bahut ».
- Une version « Wood » ou « Keramik » est un autre modèle que la version en verre.
- Conditions d'usage à dire quand elles existent : extérieur couvert pour les deux modèles Outdoor, fixation murale pour
  les consoles, câble de suspension, télécommande en option sur les versions O/LO et V/LV de Bloom (ampoules non graduables).
