# Captures de la révision éditoriale

Captures du 28 septembre 2026, effectuées dans la copie jetable locale sur le port 4331, après les migrations 0003 et 0004. Elles montrent les propositions de contenu, **pas une publication sur la base principale**.

Chromium, 1440 × 900 et 390 × 844, thèmes clair et sombre, mouvement réduit pour stabiliser les captures. Les vues sont positionnées sur les textes de la famille Tables et du modèle Skorpio. Elles ne constituent pas une comparaison pixel à pixel avec la maquette B ni un essai sur iPhone physique.
