Il ne s'agit pas d'une comparaison pixel à pixel avec une page du prototype. Les photographies sont affichées entières ; leur fond blanc appartient aux images originales.

Les captures WebKit proviennent du moteur automatisé sous Linux, pas d'un iPhone physique. Les suites vérifient aussi les galeries et accordéons au clavier, les thèmes, les menus, les liens internes, le mouvement réduit et l'absence de débordement horizontal.
